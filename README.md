# FEU Tech — Schedule & Assessment

Standalone static recreation of the FEU Tech Student Online Access and Records **Schedule and Assessment** screen.

## Run locally

Open `index.html` in a browser.

## GitHub Pages

This repository is structured to work as a static GitHub Pages site. In GitHub, go to:

**Settings → Pages → Deploy from a branch → main → /(root)**

The site is a front-end recreation only. It does not connect to a student information system, authentication service, or payment system.

## Notes

- The layout is based on the supplied Schedule & Assessment screenshot.
- Student-identifying values are masked/placeholders for a public repository.
- The FEU-style sidebar seal is recreated with HTML/CSS rather than using a private or authenticated asset.
